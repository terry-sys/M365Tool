# 应用图标

使用用户最终确认的简洁工具箱和右上角单颗白色四角星，背景色为参考截图中的 `#5073ED`。

- `toolbox-sparkle.svg`：可编辑源图。

- `toolbox-sparkle.ico`：16、20、24、32、48、64、128、256px 多尺寸图标。16–24px 使用适合小尺寸的箱体和稍大的星星。

- EXE 与窗口共用这一份 ICO。

图形基于 Microsoft Fluent UI System Icons 的 Toolbox 和 Sparkle 图标修改，遵循 MIT 许可，见 `../FluentOutline/LICENSE-Fluent.txt`（随程序复制）。
