# Fluent Outline icons

Selected icon sample: 01-outline (blue #1877F2, transparent background).

The six home icons and sidebar icons use the same Microsoft Fluent UI System Icons Regular paths. Home, Navigation and Info provide the matching home/menu/about symbols. Teams and Outlook use functional People Team and Mail symbols rather than product logos.

SVG files are the editable vector sources; 256 x 256 transparent PNG exports are embedded for native WinForms rendering. Sidebar images are cached at their scaled display size.
